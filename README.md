Suhani's Vision Board is a website made with HTML, CSS, and JavaScript. It shows images of goals and inspiration in a clean layout, with a styled background and a small intro animation. 
I made this project to  help me learn and practice basic web design, layout, and simple animations. I struggled with the the positioning of the pictures the most. I resolved this by moving all 
the individual pictures into a div so i can position all the pictures side by side without having to tamper with and write code for each one.
